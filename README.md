# 网页版声音克隆工具

基于 **GPT-SoVITS** 的个人声音克隆项目，目标：在网页上完成从声音采集到语音合成的完整流程。

## 三步流程

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│  1. 样本采集 │  →   │  2. 声音克隆 │  →   │  3. TTS 合成 │
│  录音/上传   │      │  训练音色模型 │      │  输入文字出语音│
└─────────────┘      └─────────────┘      └─────────────┘
```

| 步骤 | 说明 | 状态 |
|------|------|------|
| 1. 样本采集 | 录制/上传参考音频（1 分钟以上清晰人声即可） | 🟡 进行中（已准备参考音频） |
| 2. 声音克隆 | 用 GPT-SoVITS 训练个人音色模型 | ⚪ 待开始（本地运行学习中） |
| 3. TTS 合成 | 网页界面输入文字，生成克隆语音 | ⚪ 待开始 |

## 技术栈

- **核心引擎**：[GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS)（6.5 万+ Star 的开源项目，1 分钟语音即可克隆）
- **前端界面**：网页版（计划自定义三步流程界面）
- **运行环境**：本地部署
