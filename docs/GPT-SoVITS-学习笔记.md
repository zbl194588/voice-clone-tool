# GPT-SoVITS 学习笔记

## 项目概况

- **仓库地址**：https://github.com/RVC-Boss/GPT-SoVITS
- **Star 数**：64,993（2026-11 查询）
- **核心能力**：1 分钟语音数据即可训练出高质量 TTS 模型（少样本声音克隆）
- **支持中文**：✅ 对中文语音效果良好

## 核心目录结构

```
GPT-SoVITS/
├── GPT_SoVITS/    ← 核心算法代码（训练与推理）
├── tools/         ← 工具脚本（含 WebUI）
├── Docker/        ← Docker 一键部署方案
├── docs/          ← 官方文档
└── api.py 等      ← 对外 API 接口
```

## 对本项目有用的要点

1. **参考音频要求**：1 分钟以上、环境安静、吐字清晰的录音即可
2. **内置 WebUI**：GPT-SoVITS 自带网页界面，我们的三步流程界面可以参考/改造它
3. **API 接口**：`api.py` 提供了 HTTP 接口，网页前端可以直接调用，不用改核心代码
